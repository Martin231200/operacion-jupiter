Álgebra lineal en los 3 lenguajes

Fecha de última modificación

10 de noviembre, 2026

Cuatro operaciones de álgebra lineal que aparecen todo el tiempo en ingeniería (estructuras, circuitos, control, vibraciones), resueltas en Python, R y Julia con matrices pequeñas cuyos resultados se pueden comprobar a mano.

Nota

Sobre las salidas. Las salidas mostradas son de Python y están verificadas. El código de R y de Julia usa funciones estándar y debe dar los mismos valores, pero todavía no se ejecuta en las pruebas automáticas del sitio. Julia, además, no corre en vivo en el navegador. En Python necesitas NumPy; en Julia, el paquete estándar LinearAlgebra (viene con Julia, solo hay que cargarlo).

1. Producto de matrices y transpuesta

Datos: A = [[1, 2], [3, 4]] y B = [[0, 1], [1, 0]]. Multiplicar por B por la derecha intercambia las columnas de A, así que A·B = [[2, 1], [4, 3]]. La transpuesta de A es [[1, 3], [2, 4]].

  • Python
  • R
  • Julia
import numpy as np
A = np.array([[1, 2], [3, 4]])
B = np.array([[0, 1], [1, 0]])
print(A @ B)
print(A.T)

Salida: [[2 1] [4 3]] y [[1 3] [2 4]]

A <- matrix(c(1, 3, 2, 4), nrow = 2)   # R llena por columnas
B <- matrix(c(0, 1, 1, 0), nrow = 2)
A %*% B
t(A)
A = [1 2; 3 4]
B = [0 1; 1 0]
A * B
A'

Ojo: el mismo símbolo * significa cosas distintas. En Python (con NumPy) y en R multiplica elemento a elemento; en Julia, entre matrices, es el producto matricial. Por eso en Python se usa @ y en R %*%.

2. Determinante e inversa

Datos: A = [[2, 1], [1, 3]]. Su determinante es 2·3 − 1·1 = 5, y su inversa es 1/5 · [[3, −1], [−1, 2]] = [[0.6, −0.2], [−0.2, 0.4]].

  • Python
  • R
  • Julia
A = np.array([[2, 1], [1, 3]])
print(round(np.linalg.det(A), 4))
print(np.linalg.inv(A))

Salida: 5.0 y [[ 0.6 -0.2] [-0.2 0.4]]

A <- matrix(c(2, 1, 1, 3), nrow = 2)
det(A)
solve(A)      # sin segundo argumento, devuelve la inversa
using LinearAlgebra
A = [2 1; 1 3]
det(A)
inv(A)

Ojo: con decimales, el determinante puede salir como 5.000000000000001; por eso aquí se redondea en Python. Para saber si una matriz es singular no compares el determinante con == 0: usa una tolerancia.

3. Sistema de ecuaciones lineales

Problema: resolver 2x + y = 3 y x + 3y = 5, es decir, A·x = b con la A de arriba y b = [3, 5]. La solución es x = 0.8 y y = 1.4. Comprobación: 2·0.8 + 1.4 = 3 y 0.8 + 3·1.4 = 5.

  • Python
  • R
  • Julia
b = np.array([3, 5])
print(np.linalg.solve(A, b))

Salida: [0.8 1.4]

b <- c(3, 5)
solve(A, b)
b = [3, 5]
A \ b

Ojo: para resolver un sistema no conviene calcular la inversa y multiplicar; solve en Python y R, y el operador \ en Julia, son más precisos y rápidos.

4. Valores propios

Problema: hallar los valores propios de la A simétrica de arriba. Salen de resolver λ² − 5λ + 5 = 0, es decir, λ = (5 ± √5)/2 ≈ 1.3820 y 3.6180.

  • Python
  • R
  • Julia
print(np.linalg.eigvalsh(A))

Salida: [1.38196601 3.61803399]

eigen(A)$values
using LinearAlgebra
eigvals(A)

Ojo: los tres lenguajes dan los mismos dos números, pero no en el mismo orden: R los devuelve de mayor a menor, y Python (eigvalsh) y Julia (en matrices simétricas) de menor a mayor. Compáralos como conjunto, no por posición.

Para practicar

  1. Cambia b por [1, 0] en el ejercicio 3 y comprueba a mano que la solución cumple las dos ecuaciones.
  2. Calcula A·A⁻¹ con tu código del ejercicio 2: ¿obtienes exactamente la identidad? Revisa los decimales.
  3. Con A = [[1, 2], [2, 4]], calcula el determinante. ¿Qué pasa si intentas invertirla?

Cuatro operaciones de álgebra lineal que aparecen todo el tiempo en ingeniería (estructuras, circuitos, control, vibraciones), resueltas en Python, R y Julia con matrices pequeñas cuyos resultados se pueden comprobar a mano.

::: {.callout-note}
**Sobre las salidas.** Las salidas mostradas son de Python y están verificadas. El código de R y de Julia usa funciones estándar y debe dar los mismos valores, pero **todavía no se ejecuta en las pruebas automáticas del sitio**. Julia, además, no corre en vivo en el navegador. En Python necesitas NumPy; en Julia, el paquete estándar `LinearAlgebra` (viene con Julia, solo hay que cargarlo).
:::

## 1. Producto de matrices y transpuesta

**Datos:** `A = [[1, 2], [3, 4]]` y `B = [[0, 1], [1, 0]]`. Multiplicar por `B` por la derecha intercambia las columnas de `A`, así que `A·B = [[2, 1], [4, 3]]`. La transpuesta de `A` es `[[1, 3], [2, 4]]`.

::: {.panel-tabset}
## Python
```python
import numpy as np
A = np.array([[1, 2], [3, 4]])
B = np.array([[0, 1], [1, 0]])
print(A @ B)
print(A.T)
```
**Salida:** `[[2 1] [4 3]]` y `[[1 3] [2 4]]`

## R
```r
A <- matrix(c(1, 3, 2, 4), nrow = 2)   # R llena por columnas
B <- matrix(c(0, 1, 1, 0), nrow = 2)
A %*% B
t(A)
```

## Julia
```julia
A = [1 2; 3 4]
B = [0 1; 1 0]
A * B
A'
```
:::

*Ojo:* el mismo símbolo `*` significa cosas distintas. En Python (con NumPy) y en R multiplica **elemento a elemento**; en Julia, entre matrices, es el **producto matricial**. Por eso en Python se usa `@` y en R `%*%`.

## 2. Determinante e inversa

**Datos:** `A = [[2, 1], [1, 3]]`. Su determinante es 2·3 − 1·1 = 5, y su inversa es 1/5 · `[[3, −1], [−1, 2]]` = `[[0.6, −0.2], [−0.2, 0.4]]`.

::: {.panel-tabset}
## Python
```python
A = np.array([[2, 1], [1, 3]])
print(round(np.linalg.det(A), 4))
print(np.linalg.inv(A))
```
**Salida:** `5.0` y `[[ 0.6 -0.2] [-0.2  0.4]]`

## R
```r
A <- matrix(c(2, 1, 1, 3), nrow = 2)
det(A)
solve(A)      # sin segundo argumento, devuelve la inversa
```

## Julia
```julia
using LinearAlgebra
A = [2 1; 1 3]
det(A)
inv(A)
```
:::

*Ojo:* con decimales, el determinante puede salir como `5.000000000000001`; por eso aquí se redondea en Python. Para saber si una matriz es singular no compares el determinante con `== 0`: usa una tolerancia.

## 3. Sistema de ecuaciones lineales

**Problema:** resolver `2x + y = 3` y `x + 3y = 5`, es decir, `A·x = b` con la `A` de arriba y `b = [3, 5]`. La solución es `x = 0.8` y `y = 1.4`. Comprobación: 2·0.8 + 1.4 = 3 y 0.8 + 3·1.4 = 5.

::: {.panel-tabset}
## Python
```python
b = np.array([3, 5])
print(np.linalg.solve(A, b))
```
**Salida:** `[0.8 1.4]`

## R
```r
b <- c(3, 5)
solve(A, b)
```

## Julia
```julia
b = [3, 5]
A \ b
```
:::

*Ojo:* para resolver un sistema no conviene calcular la inversa y multiplicar; `solve` en Python y R, y el operador `\` en Julia, son más precisos y rápidos.

## 4. Valores propios

**Problema:** hallar los valores propios de la `A` simétrica de arriba. Salen de resolver λ² − 5λ + 5 = 0, es decir, λ = (5 ± √5)/2 ≈ 1.3820 y 3.6180.

::: {.panel-tabset}
## Python
```python
print(np.linalg.eigvalsh(A))
```
**Salida:** `[1.38196601 3.61803399]`

## R
```r
eigen(A)$values
```

## Julia
```julia
using LinearAlgebra
eigvals(A)
```
:::

*Ojo:* los tres lenguajes dan los mismos dos números, pero no en el mismo orden: R los devuelve de mayor a menor, y Python (`eigvalsh`) y Julia (en matrices simétricas) de menor a mayor. Compáralos como conjunto, no por posición.

## Para practicar

1. Cambia `b` por `[1, 0]` en el ejercicio 3 y comprueba a mano que la solución cumple las dos ecuaciones.
2. Calcula `A·A⁻¹` con tu código del ejercicio 2: ¿obtienes exactamente la identidad? Revisa los decimales.
3. Con `A = [[1, 2], [2, 4]]`, calcula el determinante. ¿Qué pasa si intentas invertirla?
