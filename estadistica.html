Probabilidad y estadística en los 3 lenguajes

Fecha de última modificación

17 de octubre, 2026

Los mismos cuatro problemas de probabilidad y estadística, resueltos en Python, R y Julia. Los datos están elegidos para que los resultados se puedan comprobar a mano.

Nota

Sobre las salidas. Las salidas mostradas son de Python y están verificadas. El código de R y de Julia usa funciones estándar y debe dar los mismos valores, pero todavía no se ejecuta en las pruebas automáticas del sitio: es una de las mejoras pendientes. Julia, además, no corre en vivo en el navegador.

1. Estadística descriptiva

Datos: tiempos de ciclo (minutos) de cinco piezas: 12, 15, 11, 18, 14. Media = 14, mediana = 14. Suma de cuadrados de las desviaciones = 30, así que la varianza muestral es 30 / 4 = 7.5 y la desviación estándar muestral es √7.5 ≈ 2.7386.

  • Python
  • R
  • Julia
import statistics as st
datos = [12, 15, 11, 18, 14]
print(st.mean(datos), st.median(datos), round(st.stdev(datos), 4))

Salida: 14 14 2.7386

datos <- c(12, 15, 11, 18, 14)
cat(mean(datos), median(datos), round(sd(datos), 4), "\n")
using Statistics
datos = [12, 15, 11, 18, 14]
println(mean(datos), " ", median(datos), " ", round(std(datos), digits=4))

Ojo: los tres calculan la desviación muestral (divide entre n − 1) por defecto en stdev, sd y std.

2. Distribución binomial

Problema: se lanza una moneda justa 10 veces. ¿Cuál es la probabilidad de exactamente 3 caras y de a lo más 3? Exacto: P(X = 3) = 120 / 1024 = 0.1171875 y P(X ≤ 3) = 176 / 1024 = 0.171875.

  • Python
  • R
  • Julia
from math import comb
n, p = 10, 0.5
pmf3 = comb(n, 3) * p**3 * (1 - p)**(n - 3)
cdf3 = sum(comb(n, k) * p**k * (1 - p)**(n - k) for k in range(4))
print(pmf3, cdf3)

Salida: 0.1171875 0.171875

cat(dbinom(3, 10, 0.5), pbinom(3, 10, 0.5), "\n")
# Requiere el paquete Distributions: import Pkg; Pkg.add("Distributions")
using Distributions
d = Binomial(10, 0.5)
println(pdf(d, 3), " ", cdf(d, 3))

3. Distribución normal

Problema: para una variable normal estándar, calcula P(Z ≤ 1.96) y P(−1 < Z < 1). Valores conocidos: ≈ 0.9750 y ≈ 0.6827 (la regla del 68 %).

  • Python
  • R
  • Julia
from statistics import NormalDist
z = NormalDist()
print(round(z.cdf(1.96), 4), round(z.cdf(1) - z.cdf(-1), 4))

Salida: 0.975 0.6827

cat(round(pnorm(1.96), 4), round(pnorm(1) - pnorm(-1), 4), "\n")
using Distributions
z = Normal()
println(round(cdf(z, 1.96), digits=4), " ", round(cdf(z, 1) - cdf(z, -1), digits=4))

4. Regresión lineal simple

Datos: esfuerzo aplicado x = 1, 2, 3, 4, 5 y deformación medida y = 2.1, 3.9, 6.2, 7.8, 10.1. A mano: x̄ = 3, ȳ = 6.02, Sxy = 19.9, Sxx = 10, de modo que pendiente = 1.99 e intercepto = 0.05.

  • Python
  • R
  • Julia
from statistics import linear_regression, correlation
x = [1, 2, 3, 4, 5]
y = [2.1, 3.9, 6.2, 7.8, 10.1]
pendiente, intercepto = linear_regression(x, y)
r2 = correlation(x, y) ** 2
print(round(pendiente, 4), round(intercepto, 4), round(r2, 4))

Salida: 1.99 0.05 0.9973

x <- c(1, 2, 3, 4, 5)
y <- c(2.1, 3.9, 6.2, 7.8, 10.1)
ajuste <- lm(y ~ x)
cat(round(coef(ajuste), 4), round(summary(ajuste)$r.squared, 4), "\n")
x = [1, 2, 3, 4, 5]
y = [2.1, 3.9, 6.2, 7.8, 10.1]
X = [ones(5) x]
coef = X \ y                      # mínimos cuadrados
r2 = 1 - sum((y .- X * coef).^2) / sum((y .- sum(y)/5).^2)
println(round.(coef, digits=4), " ", round(r2, digits=4))

En R el orden de coef() es (intercepto, pendiente); en Julia, con la matriz [ones x], también.

  3. En el ejercicio 4, agrega el punto (6, 12.5) y observa cómo cambian la pendiente y R².

from statistics import linear_regression, correlation
