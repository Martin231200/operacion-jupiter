Introducción a Julia

ImportanteNota

Este contenido se basa en características generales y documentadas del lenguaje Julia. Aún no contamos con material específico del proyecto para esta sección — se actualizará cuando la profa comparta el notebook correspondiente.

Lenguajes de programación de código libre

Julia

Características

  • Julia es un lenguaje compilado “just-in-time” (JIT): traduce el código a máquina la primera vez que se ejecuta una función, lo que le da un desempeño cercano a C manteniendo una sintaxis de alto nivel.
  • Fue creado en 2012 por Jeff Bezanson, Stefan Karpinski, Viral Shah y Alan Edelman en el MIT.
  • Busca resolver el “problema de los dos lenguajes”: prototipar en un lenguaje interpretado y luego reescribir en uno compilado para producción — con Julia no hace falta reescribir.
  • Tiene soporte nativo para multiple dispatch: el comportamiento de una función puede depender del tipo de todos sus argumentos, no solo del primero.
  • Es software libre, con licencia MIT.

Ventajas y desventajas de Julia

  • A favor: desempeño cercano a lenguajes compilados manteniendo sintaxis de alto nivel.
  • A favor: diseñado desde cero para cómputo científico y numérico.
  • En contra: comunidad y ecosistema de paquetes más pequeños que Python o R.
  • En contra: la primera vez que corre una función puede sentirse lenta por la compilación JIT (“time to first plot”).

Interfases y ambientes colaborativos

Instalar Julia

  • Se descarga desde https://julialang.org/downloads/, eligiendo el instalador según el sistema operativo.
  • Al terminar la instalación, Julia se puede correr desde su propia consola (REPL) o integrado a un editor como VS Code (con la extensión oficial de Julia).

Usar Julia en Jupyter

Para que Julia aparezca como opción al crear un notebook, hace falta instalar el paquete IJulia:

using Pkg
Pkg.add("IJulia")

Este paso registra el kernel de Julia en Jupyter automáticamente.

Julia en Google Colab

A diferencia de Python, Colab no tiene soporte oficial integrado para Julia — se puede usar instalándolo manualmente en la primera celda de cada sesión, aunque es menos práctico que RStudio o Jupyter local.

Primeros pasos

# Ver la versión instalada
VERSION

# Ayuda sobre una función
?println

# Salir del REPL
exit()
