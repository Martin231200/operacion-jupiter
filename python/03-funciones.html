Declaración “import”

Varias funciones de Python no se instalan de incio y que el usuario debe hacerlo. Por ejemplo, la librería math

Ver/ocultar código 
import math

Math tiene varios métodos de uso matemático, por ejemplo, el valor de \(\pi\)

Ver/ocultar código 
math.pi
3.141592653589793
Ver/ocultar código 
g=64
math.sqrt(g)
8.0
Ver/ocultar código 
math.pow(g,3)
262144.0
Ver/ocultar código 
n=2
Ver/ocultar código 
19 + n + round(math.pi) * 2
27
Ver/ocultar código 
int('111',2)

Funciones definidas por el usuario

Forma general de una función:

$ def (argumentos):$ \ $ calculos $ \ $ return (resultados)$

Ver/ocultar código 
def saludos():
  print("Saludos gente")
  print("La porra los saluda")
Ver/ocultar código 
saludos()
Saludos gente
La porra los saluda
Ver/ocultar código 
def pide_pi():
  numero_pi = math.pi
  return numero_pi
Ver/ocultar código 
pide_pi()
3.141592653589793
Ver/ocultar código 
def repetir(palabra, n):
    print(palabra * n)
Ver/ocultar código 
spam = 'Spam, '
repetir(spam, 4)
Spam, Spam, Spam, Spam,
Ver/ocultar código 
def primeras_dos_lineas():
    repetir(spam, 4)
    repetir(spam, 4)
Ver/ocultar código 
primeras_dos_lineas()
Spam, Spam, Spam, Spam, 
Spam, Spam, Spam, Spam,
Ver/ocultar código 
def ultimas_tres_lineas():
    repetir(spam, 2)
    print('(Lovely Spam, Wonderful Spam!)')
    repetir(spam, 2)
Ver/ocultar código 
ultimas_tres_lineas()

(Lovely Spam, Wonderful Spam!)
Spam, Spam,
Ver/ocultar código 
def coro():
    primeras_dos_lineas()
    ultimas_tres_lineas()

Variables y parámetros locales

Las variables y parámentros locales son aquellas cuya influencia se remita a una función.

Ver/ocultar código 
def dos_partes(parte1,parte2):
  total = parte1 + parte2
  print(total)
Ver/ocultar código 
parte1='yo '
parte2='y tu '
dos_partes(parte1,parte2)
yo y tu

    print('x es par')

Ver/ocultar código 
if x < y:
    print('x es menor que y')

    print('x es mayor que y')

    print('x y y son iguales') # Decisiones anidadas

también puede escribirse como:

Ver/ocultar código 
if x < y:
    print('x es menor que y')

          print('x y y son iguales') # Decisiones anidadas
