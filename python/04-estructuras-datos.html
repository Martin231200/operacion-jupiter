Una lista es una secuencia de valores, no deben ser del mismo tipo necesariamente. Se crean utilizando corchetes [ ]

Ver/ocultar código 
Lista_1 = [1,2,3,4,5]
Lista_1
[1, 2, 3, 4, 5]
Ver/ocultar código 
Sopes = ['Pollo', 'Chorizo', 'Frijol']
Sopes
['Pollo', 'Chorizo', 'Frijol']

Puede haber listas “anidadas”

Ver/ocultar código 
t = ['spam', 2.0, 5, [10, 20]]
t
['spam', 2.0, 5, [10, 20]]

Puede haber listas vacias

Ver/ocultar código 
Vacia = []
Vacia
[]

‘List’ nuestra los componentes de la lista

Ver/ocultar código 
list(Sopes)
['Pollo', 'Chorizo', 'Frijol']

‘Len’ devuelve el número de componentes de la lista

Ver/ocultar código 
len(t)
4

Se puede leer un elemento en específico de una lista

Ver/ocultar código 
Sopes[2]
'Frijol'

Y se puede cambiar un elemento

Sopes[1] = ‘Tasajo’ Sopes[1]

Ver/ocultar código 
Sopes
['Pollo', 'Chorizo', 'Frijol']

Esto implica que las listas son mutables, es decir, se pueden modificar

El operador ‘in’ indica si un determinado elemento pertenece a la lista

Ver/ocultar código 
'Tasajo' in Sopes
False
Ver/ocultar código 
'Chorizo' in Sopes
True

Se puede trabajar con segmentos de una lista.

Ver/ocultar código 
Letras = ['a','b','c','d','e','f','g']
Letras
['a', 'b', 'c', 'd', 'e', 'f', 'g']
Ver/ocultar código 
Letras[1:3]
['b', 'c']

Ojo: el índice empieza en la posición ‘0’

  1. Elemento de la lista
  2. Elemento de la lista
Ver/ocultar código 
Letras[0:3]
['a', 'b', 'c']

Que es lo mismo que

Ver/ocultar código 
Letras[:3]
['a', 'b', 'c']

Funciona igual de una posición inicial hasta el final

Ver/ocultar código 
Letras[2:]
['c', 'd', 'e', 'f', 'g']

O la lista completa

Ver/ocultar código 
Letras[:]
['a', 'b', 'c', 'd', 'e', 'f', 'g']

Las listas se pueden concatenar

Ver/ocultar código 
Conc=Sopes+Letras
Conc
['Pollo', 'Chorizo', 'Frijol', 'a', 'b', 'c', 'd', 'e', 'f', 'g']

O se pueden repetir

Ver/ocultar código 
Sopes*4
['Pollo',
 'Chorizo',

 'Frijol',

Ver/ocultar código 
[Sopes] * 4
[['Pollo', 'Chorizo', 'Frijol'],
 ['Pollo', 'Chorizo', 'Frijol'],
 ['Pollo', 'Chorizo', 'Frijol'],
 ['Pollo', 'Chorizo', 'Frijol']]

Sólo para listas con elementos numéricos

Ver/ocultar código 
sum(Lista_1)
15
Ver/ocultar código 
min(Lista_1)
1
Ver/ocultar código 
max(Lista_1)
5

append’ agrega al final un elemento a una Lista

Ver/ocultar código 
Sopes.append('Rajas')
Sopes
['Pollo', 'Chorizo', 'Frijol', 'Rajas']

‘extend’ agrega elementos tomados de una lista adicional

Ver/ocultar código 
Sopes.extend(['Elote', 'Queso'])
Sopes
['Pollo', 'Chorizo', 'Frijol', 'Rajas', 'Elote', 'Queso']

‘pop’ elimina el elemento de determinado índice

Ver/ocultar código 
Sopes.pop(3)
Sopes
['Pollo', 'Chorizo', 'Frijol', 'Elote', 'Queso']

‘remove’ elimina el elemento

Ver/ocultar código 
Sopes.remove('Pollo')
Sopes
['Chorizo', 'Frijol', 'Elote', 'Queso']

Una cadena no es una lista, es una secuencia de caracteres, que no es lo mismo que una lista de caracteres

Ver/ocultar código 
Nombre = 'Juan'
Nombre
'Juan'

‘list’ divide una cadena en sus elementos

Ver/ocultar código 
n=list(Nombre)
n
['J', 'u', 'a', 'n']

‘split’ en palabras

Ver/ocultar código 
Ultra='La porra te saluda'
Ultra
'La porra te saluda'
Ver/ocultar código 
Ultra.split()
['La', 'porra', 'te', 'saluda']

En este método se puede establecer el delimitador

Ver/ocultar código 
f='ex-comadre'
g=f.split('-')
g
['ex', 'comadre']

‘join’ permite concatenar listas de cadenas en una sola. Se sugiere invocarlo en el delimitador y que la lista sea el argumento

Ver/ocultar código 
h=['waiting','for','a','girl','like','you']
h
['waiting', 'for', 'a', 'girl', 'like', 'you']
Ver/ocultar código 
delimiter = ' '
j = delimiter.join(h)
j
'waiting for a girl like you'

Se puede recorrer una lista con un ciclo contador (for)

Ver/ocultar código 
for sopes in Sopes:
  print(sopes)
Chorizo
Frijol
Elote
Queso
Ver/ocultar código 
for palabra in Ultra.split():
  print(palabra)

porra

‘sorted’ ordena los elementos de una lista sin modificarla

Ver/ocultar código 
sorted(Sopes)
['Chorizo', 'Elote', 'Frijol', 'Queso']
Ver/ocultar código 
Sopes
['Chorizo', 'Frijol', 'Elote', 'Queso']
Ver/ocultar código 
sorted('Ultra')
['U', 'a', 'l', 'r', 't']

El resultado es una lista, si se desea convertirlo en una cadena

Ver/ocultar código 
''.join(sorted('Ultra'))
'Ualrt'

Un diccionario es una colección mutable no ordenada de pares de datos ‘llave:valor’ donde la llaves es única pero el valor no necesariamente

Ver/ocultar código 
mi_dicc = {'nombre':'Juan', 'edad':25 , 'profesión':'ingeniero'} # 'nombre' es la llave, 'Juan' es el valor... Los diccionarios se crean con {}
mi_dicc
{'nombre': 'Juan', 'edad': 25, 'profesión': 'ingeniero'}

Para obtener un valor a partir de la llave

Ver/ocultar código 
print(mi_dicc['nombre'])
Juan

Para agregar un valor

Ver/ocultar código 
mi_dicc['ciudad'] = 'Ciudad de México'
mi_dicc
{'nombre': 'Juan',
 'edad': 25,
 'profesión': 'ingeniero',
 'ciudad': 'Ciudad de México'}

Para modificar un valor

Ver/ocultar código 
mi_dicc['edad'] = 30
mi_dicc
{'nombre': 'Juan',
 'edad': 30,
 'profesión': 'ingeniero',
 'ciudad': 'Ciudad de México'}

Para eliminar un valor

Ver/ocultar código 
del mi_dicc['profesión']
mi_dicc
{'nombre': 'Juan', 'edad': 30, 'ciudad': 'Ciudad de México'}

Una tupla es una secuencia de valores de cualquier tipo indexados por números enteros; a diferencia de las listas, son inmutables

Ver/ocultar código 
z = 'c','o','m','p','u','t','a','c','i','o','n'
z
('c', 'o', 'm', 'p', 'u', 't', 'a', 'c', 'i', 'o', 'n')
Ver/ocultar código 
type(z)
tuple

No es necesario el uso de parentésis

Ver/ocultar código 
z1 = 'W', # Una tupla de un sólo elemento debe terminar con una ','
type(z1)
tuple
Ver/ocultar código 
z2 = 'W' # De lo contrario, es una cadena
type(z2)
str
Ver/ocultar código 
z3 = tuple('Cadena')
z3
('C', 'a', 'd', 'e', 'n', 'a')
Ver/ocultar código 
z[2]
'm'
Ver/ocultar código 
z[1:3] # La mayoría de los operadores que se aplican a listas también se pueden aplicar a tuplas
('o', 'm')
Ver/ocultar código 
tuple('arr')+tuple('ooooz')
('a', 'r', 'r', 'o', 'o', 'o', 'o', 'z')
Ver/ocultar código 
tuple('gol')*4
('g', 'o', 'l', 'g', 'o', 'l', 'g', 'o', 'l', 'g', 'o', 'l')
Ver/ocultar código 
sorted(z)
['a', 'c', 'c', 'i', 'm', 'n', 'o', 'o', 'p', 't', 'u']
Ver/ocultar código 
reversed(z)
<reversed at 0x7be14bf726e0>
Ver/ocultar código 
tuple(reversed(z))
('n', 'o', 'i', 'c', 'a', 't', 'u', 'p', 'm', 'o', 'c')
Ver/ocultar código 
z.remove('o')
---------------------------------------------------------------------------
